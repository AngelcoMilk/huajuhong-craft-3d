## 青果

五六月，化州的湿热起来了。柚子还只有拳头大，皮上覆着一层灰白的细绒，摸上去是哑的。这就是橘红——不是橘子，也不是橘子皮，是化州柚未熟的幼果外面那一层皮。

出了这片地就不行。宝山的礞石土壤，罗江、鉴江一带的小气候，换个地方种，绒毛就稀，柚皮苷就掉。旧志里只说一句：「惟署内城内者宜用。」

药典里那一句，拆开是六个动作：烫、割、去瓤、晒或焙、润透对折压平、再焙干。写进书里，是六十多年前的事；在化州乡下，它只是阿婆手上的一套动作，一代代传下来，没有图纸，也没有文字。

一百斤鲜果，最后只出四五斤干皮。

这里把那套动作，一帧一帧算了出来。

## 一颗果子，四种去处

四条线共用一个院子、一座灶、一口锅。摘果、称果、烫果是同一段代码，只换参数；下了锅，才各走各的路。

## 四条屏

进门先看见四幅挂轴，像厅堂里挂的四条屏。在哪一幅前停一停，它就往下垂一截：成品的白描一笔一笔勾出来，旁边是书上的头一句，底下一串小印依次盖过去，是这条线要走的工序。院子里的光也跟着偏——七爪是清早，大五爪是上午，压果片到了傍晚，橘红胎是一院斜阳。

点一下，那一幅的纸面铺满整屏。纸后面，院子换成这一条线的；纸一揭开，就从树下摘果开始。整个过程不换网页，地址栏照样变，浏览器的后退也认得回来的路。

## 一句古法，一章一章写上去

<table>
<tr>
<td width="50%"><img src="shots/05-book.jpg"><br><sub><b>书页</b>　做到哪一步，就描到哪一句；刚写上的那句，字旁圈一串朱圈。</sub></td>
<td width="50%"><img src="shots/06-card.jpg"><br><sub><b>题签</b>　每章开头挂出一张：其一、其二……章名落墨，一笔飞白，盖印。</sub></td>
</tr>
</table>

片子的右边，时常翻开一页线装书：四周双边，界行细细，书口贴一张朱红的书名签。书上那句古法，起先只是一行淡淡的朱红空心字，像描红本上等人来描的底样。院子里每做完一章，那一章的句子就落了墨——一个字一个字洇开、收干，写完，字旁再圈一串朱圈。

每章开头，还挂出一张竖题签：其一、其二……章名落墨，一笔飞白，盖一方印，"嗒"的一声。

到最后一章做完，整句都描满了，页脚盖一方「成」。药典里的一句话，原是这样一步一步做出来的。

## 院子里的一切，都是算出来的

不是拍视频，也不是做模型——**全部由程序生成**。

院子里每一片瓦、灶膛里每一块炭、果皮上每一根绒毛，都是算出来的，没有导入一个外部 3D 模型。声音也几乎都是算的：落水、笊篱沥水、下刀、刮瓤、压板、打结、切药，锅里的水、灶火的噼啪、炭火的嘶声，全由 Web Audio 实时合成。只有两段底色用了真实录音——院子里远处的鸟、灶膛里的火——都是 CC0，随仓库分发，出处与处理参数见 [`public/audio/CREDITS.md`](public/audio/CREDITS.md)。

纸也是算的。竹纸的纹、印泥的毛边、白描的笔触、题签上那一笔飞白，都出自噪声滤镜和几行公式，不用一张图片素材。

- **Three.js + TypeScript**，Vite 构建
- **按段拆导演**：十三个独立的小段（`src/acts/`），每条线只写「用哪几段 + 参数 + 自己的台本」（`src/lines/`）
- **一切跟着时间走**：院子、镜头、题签、书页上的落墨与圈点，都是时间的函数；拖进度、倒回去看，字也跟着退回去
- **换线不换网页**：纸盖着的时候把院子拆了重搭，显存随拆随还
- **按 1920×1080 排版**，整体缩放；断网可跑

## 怎么看

线上：https://angelcomilk.github.io/huajuhong-craft-3d/

在本地：

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5180/

| 地址 | 看什么 | 时长 |
|---|---|---|
| `/` | 入口：四条屏，任选一种 | — |
| `/?line=qizhua` | 七爪 | 3 分 44 秒 |
| `/?line=wuzhua` | 大五爪 | 3 分 44 秒 |
| `/?line=yaguo` | 压果片 | 3 分 23 秒 |
| `/?line=tai` | 橘红胎 | 2 分 03 秒 |

<kbd>空格</kbd> 暂停，<kbd>←</kbd> <kbd>→</kbd> 换章，<kbd>M</kbd> 开关声音，<kbd>F</kbd> 全屏。地址后面加 `&t=秒&pause`，跳到某一刻停住，比如 `/?line=wuzhua&t=135&pause`。

```bash
npm run build        # 类型检查 + 声音时刻检查 + 打包
npm run check:audio  # 只跑声音时刻检查（改了段落时长或音效触发时间后）
npm run fonts        # 字体子集化（改过界面文字后要重跑）
```
