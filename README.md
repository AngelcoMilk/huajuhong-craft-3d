# 七爪

**化橘红古法加工的三维演示**　·　一颗果子，四种做法，全部由程序生成

> 柚类橘红系将未成熟的果实，先投入沸水中，即捞出，将果皮割成五至七瓣，出去果瓤及内面部分白色的中果皮后晒干或焙干，再以水润透，对折以木板压平，再焙干即得。
>
> ——《中国药典》1963 年版一部「橘红」条

这句话写在六十多年前的药典里。再往前，它只是化州乡下阿婆手上的一套动作，一代一代传下来，没有图纸，也没有文字。

五六月，青果还没熟透，皮上覆着一层灰白的细绒，手摸上去是哑的。摘下来，滚水里一烫，青绿转成黄绿，皮就软了。刀从果顶下去，割到四分之三收住——不能割透，底部还连着。几瓣翻开，像一朵花。掏出果瓤，再刮掉内面那层白色的中果皮，摊在竹匾上晒，或者架在焙炉上烘干。干透了，洒水润透，对折，用木板压平。再焙一次，就成了。

一百斤鲜果，最后只出四五斤干皮。这是七爪比别的形态贵几倍的原因。

## 这个项目

把上面那段工艺，用代码重新做一遍。

不是拍视频，也不是做模型——全部由程序生成。院子里每一片瓦、灶膛里的每一块炭、果子表皮上的每一根绒毛，都是算出来的，没有导入任何外部 3D 模型。声音也一样，落水、下刀、刮瓤、灶火、夜里的蛐蛐，全部由 Web Audio 实时合成，没有一个音频文件。

同一颗果子，按重量会走向四个不同的结局。分叉点在开头：摘下来的果过一杆秤——不到 150 克的做胎，超过 230 克的才够格割瓣。

## 怎么跑

```bash
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5180/

| 地址 | 看什么 | 时长 |
|---|---|---|
| `/` | 入口页，四种做法 | — |
| `/?line=qizhua` | 七爪 | 约 3 分 45 秒 |
| `/?line=wuzhua` | 大五爪 | 约 3 分 40 秒 |
| `/?line=yaguo` | 压果片 | 约 3 分 20 秒 |
| `/?line=tai` | 橘红胎 | 约 2 分钟 |

加 `&t=秒&pause` 跳到某一刻停住，比如 `/?line=wuzhua&t=135&pause`。声音开关快捷键 <kbd>M</kbd>。

```bash
npm run build     # tsc --noEmit && vite build
npm run fonts     # 字体子集化（改过文案后要重跑）
```

## 技术上是怎么做的

- **Three.js + TypeScript**，Vite 构建，版本锁死
- **全程序化**：没有 .glb / .gltf / .fbx。布、竹编、铁锅、炭火、绒毛、水汽都是几何体加着色器
- **声音也是算的**：Web Audio 实时合成。动作音（落水、笊篱沥水、下刀、刮瓤、洒水、压板、翻面、打结、切药）按各段自己的时间点报出来；环境声（风、叶子、鸟、蛐蛐、锅里的水、灶火、炭火）按场景状态和离镜头远近调
- **四段共用前段**：摘果、称果、烫果是同一份代码，只换参数
- **按段拆导演**：十三个独立小动画（`src/acts/`），每条线只写"用哪几段 + 参数 + 自己的台本"（`src/lines/`）
- 1920×1080 排版，整体缩放；断网可跑

## 目录

```
src/
  main.ts        入口，按 ?line 选一条线
  director.ts    导演：把各段按顺序串起来
  stage.ts       这一幕的舞台状态
  camera.ts      镜头
  acts/          十三个独立小段：摘果、称果、烫果、割、晒、折、压、焙、捆、
                 压果、切片、连烘、结尾
  lines/         四条线（七爪、大五爪、压果片、橘红胎），各带台本与参数
  world/         院子世界：灶、铁锅、案台、竹匾、焙炉、柚子树、水缸、
                 杆秤、压石、切药刀、簸箕、玻璃罐…
  gfx/           渲染基础：程序化几何、着色器、后期、环境光
  audio/         实时合成的声音
  ui/            封面、章节标题卡、字幕、本子、结尾、控制条
public/fonts/    思源宋体、霞鹜文楷（已子集化）
scripts/         字体子集化、逐帧截图
```

工艺依据《中国药典》1963 年版与 2006 年国家地理标志产品公告；形态与参数核对过地方志、行业资料与专利文献。凡资料里没有的（比如古法到底压多久、去瓤用的究竟是什么铲），代码里按功能推演，不假装是考据。
